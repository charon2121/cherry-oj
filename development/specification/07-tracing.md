# 7. 依据与证据

主说明链接实际使用的产品规则、架构、契约或旧工作；不要复制上游长篇内容。涉及已有编号的引用继续保留编号和路径，新工作不用申请编号或维护关系数组。

验证写明做了什么、在什么条件下得到什么结果。环境或版本会影响结论时一并记录；测试只通过部分内容、无法执行或根因不明时直说，不把推断写成事实。

代码待办写清原因和退出条件，有现成工作、issue 或说明时链接它；没有记录时也可以在注释里把问题说清，不为了 TODO 强制启用文档系统。历史 TASK 锚点继续可查。

历史原件只读，[迁移清单](../migration.json)保存摘要用于检查。继续旧工作时，新的结果写进当前短说明或新附件，不修改原件伪装成当时就已确认。
