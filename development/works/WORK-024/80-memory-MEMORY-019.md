# MEMORY-019：重新设计登录页视觉与体验

## 背景

登录页是 Cherry OJ 的第一条认证入口。原页面功能可靠，但“居中卡片加大片空白”的构图没有延续主页
和导航已经建立的专注工作区体验；WORK-024 在不改变认证能力的边界内重新设计它。

## 决定与原因

确定原则：登录必须保持唯一主要动作；品牌叙事与辅助图形只能帮助理解和建立氛围，不能产生新入口或
遮盖状态。用户选择的第 2 个方向以左侧连续表单节奏和右侧低对比字景解决空旷感；必须使用现有
semantic token、共享组件、真实文字和 Lucide 图标重新实现，生成图只提供结构与层级参考，不是可复制
的颜色、尺寸、背景资产或虚构内容真源。

## 尝试与教训

现有小型居中 Card 证明了表单与错误流程，但在大画布上显得临时。视觉探索分别尝试双栏叙事、单画布
字景和整块登录区三种方式；共同教训是不能靠新增功能、统计卡片或营销内容填满空间。实际实现中先把
路由请求编排与页面级视图分开，再用共享 Field、PasswordField、Button、ErrorNotice 和 semantic token
还原结构；同尺寸对比发现容器、纵向节奏和字景对比度偏差后，两轮修正即可收敛，无需修改设计系统。

## 已知问题

当前账号仍由管理员开通，没有注册、找回密码、第三方登录或主题切换。这些产品能力不能借视觉改版
提前出现。生成稿使用了设计系统外的超大 display 字号和密码 placeholder；实现保留最大现有字号与
共享密码组件合同，把两者作为非阻断 P3，而不是为单页创建例外。浅色主题与 320px 已由 E2E 验证。

## 重新考虑条件

交付账号申请/注册、忘记密码、多因素认证、第三方登录、租户/组织选择，或全局 Shell 与设计系统发生
变化时重新考虑登录页的信息架构；仅增加业务页面不应改变登录主流程。
