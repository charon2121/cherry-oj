# PLAN-031：统一后端服务配置

## 目标

按用户最终确认的标准 application-local.yaml 方向重构五个后端服务。

## 改动区域

五服务 YAML、POM、配置绑定校验及相关测试，IDE、后端 Compose 示例、忽略规则及文档；不扩展 Web/Go 实现。

## 阶段与顺序

1. 盘点五服务字段、默认值、环境变量、私有值及所有 Spring 测试启动方式。
2. 统一基础文件、local 示例及私有文件，默认 local，完整迁移既有值；校验各调用关系。
3. 同步打包排除和测试隔离，不能先把私有资源引入再忽略发布安全。
4. Compose 非 local Profile 与环境覆盖验证；清理旧 .properties/import/VM 参数和重复入口。
5. 五服务本地加载/启动、后端回归、发布产物检查及集成运行验收，记录缺口。

## 并行与依赖

顺序执行，不启动子智能体。用户已确认方向并要求实施；WORK-046 意图闸仍须由用户签署，智能体不能代签。

## 迁移与交付

私有备份后等值迁移，不打印秘密，不重置密码。新方式通过验证再删除旧入口。交付后端文件和可复现验证证据；不 commit/push，不实际生产发布。

## 风险

默认 local 影响测试与容器，必须显式隔离；JAR 重打包及 target 残留可能带入秘密，检查最终产物。真实 Linux 依赖不可用时不假报集成通过。

## 验证

CHANGE-012#AC-001 至 AC-006。配置探针之外，运行适当后端测试与可用环境真实集成；不通过自动重试、清空 Redis 或伪造节点环境绕过失败。

## 回退

恢复原私有文件与配置入口，不改数据库/数据卷；在隔离环境检查回退步骤，不以用户当前进程做破坏性演练。
