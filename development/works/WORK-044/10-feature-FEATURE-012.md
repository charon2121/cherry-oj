# FEATURE-012：题目内自定义输入运行

## 为什么做

用户写完一段代码后，需要先用自己准备的数据看看程序实际输出什么，再决定是否正式提交。本功能让用户在题目工作台完成这一小步，不离开题目、不覆盖草稿，也不把调试尝试混入提交记录。

## 使用者

已登录且状态正常的 USER 与 ADMIN，权限相同。

## 入口

入口是题目右侧代码区下方的“运行”。沿用 C++ ACM 完整程序；左侧“题目描述 / 提交记录”保持现有结构。

## 正常流程

在代码下方填写自定义输入，或明确选择一个题目样例的输入 → 点击运行 → 查看本次输出、错误输出和资源用量 → 修改代码或输入后再次运行 → 需要判定正确性时点击正式提交。

## 业务规则

- REQ-001：每次只运行一份输入，允许空输入，支持选择任一个已公开样例的输入。样例只复制输入，不自动运行；覆盖非空且不同的输入前确认。
- REQ-002：运行与正式提交分开，不新增 Submission、JudgeTask 或 Kafka 事件，不影响提交历史与题目通过状态；不建设运行历史页。
- REQ-003：只执行用户点击时的代码、输入、账号及题目版本快照。运行期间可以继续编辑；结果标明其对应旧快照，不能悄悄变成后来修改内容的结果。
- REQ-004：首版不提供预期输出输入框、不自动比对答案。正常退出显示“运行完成（未校验答案）”，不能显示 AC 或“通过”；样例同样如此。
- REQ-005：返回标准输出、错误输出、编译诊断（适用时）、CPU 时间与内存峰值。区分无输出、输出被截断、编译失败、超时、内存/输出超限、运行错误、平台故障；编译未通过时不伪造运行资源为 0。
## 边界与失败

- REQ-006：空代码不可运行；输入/代码大小、频率、并发及执行时间均受服务端限制。超限明确解释，繁忙可以稍后手动重试，不无限排队。
- REQ-007：未登录、禁用账号、强制改密不可运行；题目不再公开或版本变化时拒绝新运行并引导打开当前版本，不擅自切换草稿。
- REQ-008：账号变化/退出、题目或版本切换后隐藏旧结果并取消等待，迟到响应不得展示。载入历史代码不会触发运行；运行期间切换左侧 Tabs 不丢编辑器状态。
- REQ-009：网络超时/断线显示“本次运行结果未能确认”，不冒充程序 TLE，不自动重复执行。刷新/离开不恢复运行结果；输入与结果首版只在当前页面内存保存，提示刷新将清除输入，源码继续沿用现有本地草稿。
## 要求

- REQ-010：运行占用独立的限流及服务执行槽位，不进入正式判题 Worker 队列。共享执行节点的 CPU 竞争仍可能影响耗时，不把自测资源值当正式提交成绩。
- REQ-011：程序输入、源码及输出按私有数据处理，不写 URL、日志、遥测正文或新增本机缓存，不返回隐藏测例/答案、内部凭据、宿主路径或对象存储引用。
- REQ-012：自定义输入、运行结果、提交结果在右侧编辑器下方以 Tabs 呈现；操作区与结果关联清楚。支持键盘、双主题、320px、200% 等效视口、forced-colors、reduced-motion；长文本在各自文本区域滚动，不撑宽页面。

## 验收标准

- AC-001：空输入程序、手写输入与样例输入能运行；普通 stdout、成功退出但写 stderr、空输出和多行 UTF-8 内容正确展示。默认不比对，无 AC/WA 语义。
- AC-002：CE、RE、TLE、MLE、OLE 与平台故障分别显示；超长/非法编码/控制字符输出受控展示，截断标志与字节计数有真实含义，不凭空声称完整输出。
- AC-003：运行前后 Submission/JudgeTask/Outbox 数量及提交历史不变，正式提交/结果恢复/历史回看全量回归通过。
- AC-004：代码/输入快照、版本变化、跨账号迟到响应、多标签切换、刷新和断线均不串写、不自动重跑、不污染草稿。
- AC-005：认证/CSRF/预期账号校验、内部服务鉴权、节点环境校验、输入和响应字节上限、原子限流、并发满拒绝及超时释放均有反例测试；日志无私有正文。
- AC-006：真实 Linux sandbox 完成编译执行、死循环、输出爆量测试；Go trial 保留正式判题语义，标准错误可独立返回；不能仅凭 Web mock 认定后端可用。
- AC-007：设计系统八问逐条回答，截图与交互验证通过；新后端实际重启/版本生效和真实账号端到端验收有证据。

## 不做什么

CORE、多语言、多组批量运行、预期输出比较、交互式终端/逐步调试、取消远程任务按钮、运行历史/分享、云输入草稿、异步运行队列、WebSocket、统计、资源配置管理页不在本轮。

## 待确认项

提交审核的推荐方案：单组输入且不比对；右侧底部三 Tabs；输入/结果仅内存保存；同步有界运行；大小/频率/超时建议见 DESIGN-038。它们均待意图闸整体确认，未获授权前不写业务代码。
