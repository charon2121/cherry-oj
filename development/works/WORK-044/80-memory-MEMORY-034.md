## 本轮回归发现

仅用 fakeSandbox 会漏掉 FileSource 空文本被 omitempty 编码成 {} 的错误；已改 EOF 并加入真实 JSON 回归。独立 trial 包需加入服务错误处理器范围，否则业务503会变500。大输出后空程序报281927680 bytes，显式 Linux 隔离回归用于追踪该已知限制，不能拿 macOS普通回归通过替代。

2026-09-08 专项排查：最小Linux实验确认 Go CLONE_VM + exec 保存旧地址空间峰值，使约6MiB目标被wait4报告约306MiB。FreeOSMemory不能清除历史峰值；经新启动器再次创建目标时，目标wait4恢复约6MiB，但启动器自身wait4仍受污染。候选启动器必须回传真正目标的统计；尚未实施，不能把实验可行当作安全执行后端完成。

用户后续决定：阅读排查后暂缓修复内存统计，当前基础沙箱限制不再阻塞本轮功能继续验收；后续真正的 Linux 隔离沙箱工作应复用现有回归。该决定不代表压力测试通过或功能验收闸已签署。
