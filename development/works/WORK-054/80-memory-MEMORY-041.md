# MEMORY-041：不要把软件源索引可达等同完整下载恢复

## 背景

真实业务CI已能完成认证、部署与校准；浏览器诊断尚未运行，又遭遇rootfs软件包准备网络失败。

## 决定与原因

用户已签署意图闸并允许实施，默认关闭的同源连接回退已完成本地实现与验证；独立复核和Linux实跑已完成，原生成功但两个Linux准备任务仍耗尽下载总期限。默认部署行为保持，不能为CI改变包锁和TLS要求。

## 尝试与教训

三次完整准备尝试失败；本地索引200与部分包连接超时可以同时发生。逐DNS端点对照显示差异，但没有GitHub失败peer时不能补写确定归因。

## 已知问题

下载恢复尚不稳定，浏览器失败仍待定位；WORK-050未完成，WORK-049不启动。

## 重新考虑条件

连接回退仍失败、证书或包版本失效、需要代理/换源/扩预算时，必须重新审核方案与支持条件。

## 新证据与限制

68c91d4的CI34580313653中，同源地址回退真实发生，native全部56包及10项原生测试通过；kernel/business连接也成功，却在240秒下载总期限终止。TLS连接成功不能证明HTTP或包读取完成；map按输入顺序输出也不能用来计量并发下载完成数。下一步先取得有界逐包进度，再决定策略，不能由一次原生成功推导整个CI恢复。
