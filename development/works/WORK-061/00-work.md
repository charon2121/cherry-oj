# WORK-061：judge 进程内调用 C 执行器并移除 sandbox HTTP 服务

类型：维护 · 历史工作

## 为什么做

独立 HTTP sandbox 服务增加部署、通信和重复管理成本。

## 打算怎么解决

把执行层放进 judge 进程，直接调用 C 执行器。

## 范围和代价

用户确认了减少独立故障隔离的代价；判题与执行职责仍分开。

## 怎样算完成

单个 judge 能完成原判题链路，执行限额和必要回归保持。

## 历史结果与资料

原状态仍为 todo，正式闸待签，但已有实施和通过的验证记录。迁移保留这个差异，不补签或推断人工接受。
