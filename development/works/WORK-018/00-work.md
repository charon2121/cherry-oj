# WORK-018：解除 Web 对设计系统文档目录的依赖

类型：维护 · 历史工作

## 为什么做

Web 构建依赖文档目录，删除文档就可能影响应用运行。

## 打算怎么解决

把运行和构建所需的设计值、工具与合同放回 Web 所属目录。

## 范围和代价

文档解释规则，应用持有运行资产；需同步所有消费者。

## 怎样算完成

移走文档后 Web 仍能构建、运行并验证设计系统。

## 历史结果与资料

原记录标为已实施；技术完成与人工接受需分别查原始记录。
