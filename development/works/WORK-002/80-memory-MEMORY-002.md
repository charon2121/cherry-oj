## 实施教训与后续范围

- Go 既有 PE 必须贯通所有消费者。原始 Judge 响应含私有摘录，传输上限与安全 lifecycle 的公开上限不能混为一谈。
- 提交恢复入口跨题目版本稳定，原请求体冻结旧版本；CSRF 可更新，但编辑器所属账号的一致性前置条件不能随会话悄悄变更。
- 隔离脚本不得全量继承宿主环境：Spring 的直接环境属性会覆盖 CHERRY_* 占位。测试采用白名单并注入假外部配置验证。
- 聚合配置清单测试位于 user-service 的测试目录；更新其明确分类不等于允许修改账号业务。
- 本轮隔离验收发现既有 user-service 的 JwtIssuedAtValidator 把签发时间限制为当前时间前后 30 秒，与 2 小时 token 有效期冲突。
  创建测试账号放在前置准备阶段；没有修改账号服务业务。后续应单独修复并补“已签发超过 30 秒仍在有效期”的回归。
  本轮提交服务的用户 JWT 验证使用 identity-security-support，不采用该错误的最大令牌年龄检查。
