# WORK-026：为 Java 服务提供可直接启动的本地默认配置

类型：基建 · 历史工作

## 为什么做

Java 本地启动依赖零散手工配置，首次开发容易失败。

## 打算怎么解决

提供清楚的本地默认配置与启动行为。

## 范围和代价

生产环境缺少必需配置仍要拒绝启动。

## 怎样算完成

本地可按默认入口运行，生产误配置不会静默放行。
