# FEATURE-011：题目内提交记录与代码回看

## 为什么做

用户已经能在题目页提交代码并获得结果。本次让用户在同一个工作台切换题目描述和自己的本题提交记录，读回历史代码并在确认后载入右侧编辑器，保留当前写题上下文。

## 使用者

已登录 USER 与 ADMIN，均只能使用自己的提交。管理员身份不自动获得他人源码读取权。

## 入口

现有 /problems/$slug 题目工作台左侧提供“题目描述”和“提交记录”两个 Tab，各自对应独立 panel；右侧代码编辑器持续保留。提交记录只展示当前账号在本题的记录，详情在同一 panel 内打开并可返回列表。原 submissionId 结果恢复链接继续有效。

## 正常流程

打开题目 → 左侧切到提交记录 → 选择记录 → 在左侧查看当时代码与结果 → 复制代码或确认“载入编辑器” → 在右侧继续修改。切换 Tab 和查看记录均不改变右侧草稿。

## 业务规则

- REQ-001：列表限定当前账号与当前题目，按 created_at 从新到旧排列并保证同时间稳定顺序；默认每页 20 条，支持分页与判定筛选。题目内不增加重复的题目标题搜索。URL 保留 Tab、页码、判定与选中记录，刷新和返回列表可恢复。
- REQ-002：行内展示提交编号、判定或排队/判题状态、语言和时间；同题标题无需逐行重复。资源用量放详情。判定筛选仅匹配已有判定的记录，“全部”包含处理中记录；没有提交和筛选无结果分开显示。
- REQ-003：详情显示当时的完整用户原始代码，只读、高亮、可复制，以及已有安全结果信息：题目版本、语言、提交时间、判定、资源用量、允许公开的通过数量、编译诊断与安全故障说明。缺失资源值不能展示为 0。不展示内部送判源码、隐藏测试输入输出、差异或内部地址。
- REQ-004：历史提交不随草稿修改或题目更新改变；旧版本提交仍归当前题目的提交记录，详情显示提交时标题和版本。题目下架不删除个人历史；跨题目的历史找回入口留待未来个人简介页。
- REQ-005：历史详情提供“载入编辑器”，在当前工作台中确认后替换右侧草稿；有现存草稿或未保存编辑时明确替换后果，取消不改草稿。题目版本更新时显示历史与当前编辑版本，明确切到当前可提交版本后再确认载入。此动作不提交、不重判、不修改历史。
- REQ-006：题目工作台已打开后若发现题目不可访问，停止载入和提交；已加载的本人历史仍可复制，不公开已下架题面。重新进入不可访问题目继续遵循现有 404，不为本轮新增找回页。会话失效/切换账号立即隐藏代码并取消旧请求，迟到响应不得展示或写入草稿。
- REQ-007：普通用户和管理员都不能查询他人提交列表或代码；不存在与不属于自己的提交统一返回 404。列表和源码不公开缓存，源码不进入 URL、日志或新增本机持久缓存；仅用户确认载入后按现有草稿机制保存。
- REQ-008：详情中的进行中结果自动更新至终态；源码独立读取一次，不随结果轮询反复下载。列表提供刷新入口，首版不后台高频轮询整页。查询失败保留同账号已加载结果并允许重试，不能伪装为无记录。

## 要求

- REQ-009：页面沿用 WorkbenchPageTemplate，左侧 Tabs panel 内使用现有 Toolbar/DataList 与只读 TextEditor；不嵌套整页列表或详情模板。切换 panel 不卸载右侧编辑器或重置其内容、撤销栈和光标；按设计系统八问交付。
- REQ-010：新读取接口与前端生成类型以公开契约为准，不改变原正式提交、结果恢复和判题状态机。

## 边界与失败

未登录引导登录后回到原入口；强制改密沿用现有规则。复制失败提供可选择代码及重试。加载源码失败不妨碍查看结果，但再次编辑不可用。载入前再次核对账号、题目与目标版本；请求期间切换题目或草稿发生并发变化，需要重新确认。多标签草稿冲突沿用现有冲突提示，不静默覆盖。

## 验收标准

- AC-001：题目描述/提交记录 Tab 可切换，本题本人列表分页、筛选、打开详情、返回与刷新保持状态；同时间稳定排序，计数/空状态准确；无新增全局导航或独立提交页。
- AC-002：同题不同版本的新旧提交可回看原始代码、真实结果、版本及资源信息；历史不被题目更新篡改，隐藏数据与内部源码不泄漏。
- AC-003：左侧切 Tab 和查看记录不影响右侧编辑缓冲、撤销栈与光标；载入经确认只改目标草稿，取消/失败不改；版本变化明确提示，题目不可访问时禁止载入，不自动提交。
- AC-004：未登录、普通用户越权、管理员越权均受限；切换账号、登出及迟到响应不泄漏源码或串写草稿，返回不可访问详情为 404。
- AC-005：结果轮询终止于终态；源码不随轮询重复请求；错误可恢复、复制失败有替代办法，现有正式提交和恢复流程不回归。
- AC-006：两个主题、320px、200% 缩放、键盘、长中文、forced-colors、reduced-motion 检查通过，工作台和 panel 使用现有组件，Tabs 焦点与窄屏折叠语义正确，逐条回答八问并提供截图。
- AC-007：公开契约和生成类型一致，跨服务/数据库/前端测试及读权限回归通过，查询受页大小约束，既有数据无需回填且判题状态机不变。

## 不做什么

本轮不新增 /submissions 或独立提交详情页面，不改用户全局导航，不建设个人简介页、跨题目历史 UI 或题目 id 解析接口。全局“我的提交”未来仍计划提供，个人简介页是用户提出的候选位置，具体结构待后续工作确定。其余自定义运行、统计、CORE、新语言、他人提交管理、公开分享源码、diff、云草稿、删除、导出、重判和 Judge/Kafka 改动均不在本轮。

## 待确认项

用户已明确本轮采用题目工作台左侧 Tabs；全局提交历史保留未来方向，可能放在个人简介页。本文及下游已据此修订；整份实现方案仍待意图闸审核。
