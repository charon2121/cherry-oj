# MEMORY-033：题目内提交记录与代码回看

## 背景

本轮按用户澄清采用题目左侧 Tabs；跨题目的全局历史未来可能放个人简介页，不在本轮实现。本功能承接 WORK-002 正式提交和 WORK-041 编辑器；历史原始源码已持久化，不需要从 JudgeInput 恢复。

## 决定与原因

采用独立源码端点和当前版本确认载入，结果轮询不下载源码。历史查询绑定账号与题目；账号改变后拒绝迟到结果。载入确认记录原草稿，另一标签页改变草稿时确认失效。

## 尝试与教训

单次提交“能查结果”不等于历史列表已完成；同一语言当前 ACM 原始代码与送判代码可能相同，也不能因此公开内部 Input 对象。

## 已知问题

实现与自动验证已交付，用户实际环境复核通过，正式验收闸待签署。大源码和最大分页需要按 JSON 转义后体积设有界网关缓冲；紧凑筛选隐藏标签应在控件定位范围内，避免 320px 页面横向溢出。

## 重新考虑条件

历史题面浏览、CORE、新语言、大规模历史查询或公开源码分享需要独立范围和权限决策。

- 2026-09-07：按用户澄清收敛为题目工作台左侧 Tabs；撤回全局页面、独立详情页、题目解析及导航修改范围，未来个人简介页仅记录为候选方向。

- 2026-09-07：新增 Java Controller 方法后，旧 IDEA 进程不会自动注册新路由。实际验收需重启 gateway-service 与 submission-service；本轮 405 在用户重启后消失，列表/源码实际请求为 200。
