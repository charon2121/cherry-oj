# WORK-008：建立 Web 到 Gateway 的 REST 基础连通模块

类型：基建 · 历史工作

## 为什么做

前后端只有独立骨架，还没有证明浏览器能正常访问 Gateway。

## 打算怎么解决

提供最小只读状态接口，建立统一请求、响应校验和失败展示。

## 范围和代价

接口只证明 Gateway 连通，不代表数据库或整套服务健康。

## 怎样算完成

浏览器能展示加载、成功、失败，并能主动重试。

## 历史结果与资料

原记录已验证。这里沿用当时的结果，本次没有重新执行业务验收。
