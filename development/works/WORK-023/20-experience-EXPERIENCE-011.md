# EXPERIENCE-011：设计双端导航栏与导航功能组件

## 体验类型

以用户体验为主，同时定义新增页面接入导航的开发体验。延续 Cherry OJ 的 Focused Workspace：导航低噪、
紧凑、可预期，当前任务比全局控件获得更高视觉对比度。

## 入口与主流程

### 用户端桌面

Header 从左到右为“Cherry OJ 品牌 → 主导航 → 弹性空白 → 账号区域”。品牌和“首页”均可返回首页，但
前者表达产品归属，后者表达当前信息架构；当前页面通过 `aria-current`、文字权重和轻量表面共同表达。

访客的账号区域只有“登录”。登录后显示紧凑账号触发器（用户图标、可截断用户名、展开提示）；打开后
按以下优先级排列：

1. 只读身份摘要；
2. 首次改密警告或“修改密码”；
3. ADMIN 专属“管理中心”；
4. 分隔后的“退出登录”。

首次改密状态在触发器外观与可访问名称上同时可感知，避免用户必须先猜测并打开菜单。退出是账号危险
动作，使用设计系统 danger/destructive 语义，不以品牌色表达风险。

### 管理端桌面

Header 从左到右为“管理移动菜单触发器（桌面隐藏）→ Cherry OJ / 管理中心 → 弹性空白 → 返回用户端 →
账号菜单”。Header 负责空间与身份，不出现 Dashboard 或业务页面的重复链接。

Sidebar 顶部先显示“管理”分组。Dashboard 为一级叶子；“账号管理”为展开按钮，“用户账号”为二级叶子。
进入叶子时父组自动展开；用户可展开/折叠非当前分组，当前页面所属分组保持展开，让位置关系持续可见。

### 窄屏

用户端和管理端都保留品牌、带“导航”文字的菜单按钮与账号触发器。主导航/管理导航进入左侧 Sheet，
标题与描述说明它会切换页面；项目顺序、权限过滤、图标和当前态与桌面一致。选择叶子后立即关闭，焦点
随路由进入新页面；仅关闭 Sheet 时焦点回到触发器。

### 后续页面接入

用户端新增真实题库或提交记录后，在预留顺序中加入类型化叶子项；管理端新增能力时先判断是独立一级
入口还是业务分组中的二级叶子。存在真实父页面的内容页可以在 Main 页标题上方使用面包屑，但全局
Header 不随页面层级增长。

## 异常状态

- Session 加载中：账号位置显示短状态文本，不闪现登录或管理入口，Header 尺寸尽量稳定。
- Session 加载失败：显示“登录状态加载失败，重试”，保留 Header 与 Main；重试不刷新业务页面。
- 未登录：只显示登录，不显示空账号菜单。
- 首次改密：账号触发器显示警示语义，菜单第一操作为“请先修改密码”；既有路由保护仍决定是否强制跳转。
- 退出中：菜单项文案为“退出中…”，禁用重复触发；关闭菜单后重新打开仍可读到状态。
- 退出失败：菜单内或紧邻触发器显示简洁错误并允许再次退出，辅助技术即时读出；不清空有效 Session。
- 无权限：USER 不看到管理入口；直接访问 `/admin/*` 继续由 guard 处理，导航自身不承担授权。
- 导航项为空：不渲染空分组、分隔线或占位按钮；品牌和账号区域仍形成完整 Header。

## 交互与文案

- 使用稳定名词：“首页”“管理中心”“Dashboard”“账号管理”“用户账号”“修改密码”“退出登录”。
- 同一动作在桌面、Sheet 与账号菜单中保持相同文案，不使用“个人中心”等尚无对应页面的名称。
- 菜单触发器使用按钮，导航叶子使用链接，分组触发器不同时承担路由；不使用 hover 才能发现的动作。
- Header 高度沿用现有壳层，不增加第二行工具栏；长中文优先收进菜单，而不是压缩触控目标。
- Lucide 图标只帮助扫视，始终配合文字；品牌不使用伪造 Logo、emoji 或自绘 SVG。
- 当前项使用克制表面和清晰文字，不使用强烈品牌填充；导航退后于 Main 中的主要任务。

## 可访问性

- 保持“跳到主要内容”、唯一 Main 和各自可命名的 `nav`；DOM 顺序与视觉/Tab 顺序一致。
- Tab 到触发器，Enter/Space 打开菜单或分组，方向键按 shadcn 菜单合同移动，Escape 关闭并恢复焦点。
- Dropdown Menu/Sheet 使用底层 Base UI 的焦点管理，不手写全局键盘监听。
- 当前页使用 `aria-current="page"`；分组暴露 `aria-expanded`；纯装饰图标 `aria-hidden`。
- 触控目标、焦点环、错误、警告和当前态符合设计系统；forced-colors 下不只依赖背景色表达。
- 320px、200% 缩放、长用户名下不产生横向滚动；截断文本保留完整可访问名称。
- reduced-motion 下关闭非必要过渡，菜单可用性不依赖动画完成。

## 调试与恢复

导航定义与渲染分离：组件测试可输入角色、pathname 和菜单模型，判断可见项、当前项与分组展开；
Storybook 固定展示访客、USER、ADMIN、首次改密、错误、窄屏 Sheet 和管理子菜单状态。若账号菜单或共享
模型引发回归，可回退到 WORK-020 的直接 SessionActions 与静态数组，不涉及数据迁移或服务端恢复。
