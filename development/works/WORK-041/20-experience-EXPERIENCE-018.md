# EXPERIENCE-018：建立题目阅读与 Monaco 编码工作台

## 体验类型

用户端持续读题与编码工作台。采用 WorkbenchPageTemplate 的答题布局，参考 LeetCode 的题面/代码区
组织方式；外观继续使用 Cherry OJ 的近黑/纯白、冷灰层级与细分隔线。

## 入口与主流程

1. 从题库进入原题目地址，顶部直接显示返回题库、题目名称/版本与账号入口。
2. 桌面左侧约一半空间用于题面，按题目说明、输入、输出、数据范围、样例呈现；样例明确标注输入与
   输出，可复制。右侧约一半用于代码，工具条显示 C++、ACM 和“恢复起始代码”。
3. 编辑器占据右侧主要高度，底部状态/操作区持续显示本机保存状态与暂未开放的运行、提交；没有大块
   登录说明卡、假提交列表或结果占位表。
4. 已登录用户直接写代码；访客看到只读起始代码预览和“登录后编写代码”，登录后回到原题。
5. 窄屏以“题目 / 代码”切换保留足够宽度，默认题目；切换只改变可见区域，不重置草稿。

## 异常状态

| 情况 | 用户看到的内容 | 恢复方式 |
|---|---|---|
| 会话加载 | 正在确认登录状态 | 完成前不显示误导性登录 CTA |
| 会话查询失败 | 登录状态暂时无法确认 | 重试；题面可读，已有代码不被清空 |
| 未登录/会话失效 | 登录后编写代码 | 返回原题；原账号代码从可见区域移除 |
| 必须改密 | 修改密码后继续 | 复用系统改密入口，后续恢复原账号草稿 |
| 草稿保存失败 | 未保存到本机，请复制备份 | 继续编辑/复制；离开时提示 |
| 跨标签页修改 | 此草稿在另一标签页已更新 | 保留当前文本，由用户选择加载或覆盖 |
| 编辑器加载失败 | 编辑器加载失败 | 重试；复制已恢复文本，不重置草稿 |
| 题目不存在 | 题目不存在或尚未公开 | 返回题库 |
| 运行/提交不可用 | 暂未开放 | 本轮无假成功、无额外登录要求 |

## 交互与文案

草稿状态描述本机保存，不写“已提交”或“已同步”。恢复起始代码采用现有确认弹窗，先显示影响再覆盖。
代码语言与起始代码来自已发布题目；不硬编码 A+B 解答。首版采用固定双栏与窄屏切换，不增加拖拽布局
或多文件 IDE 功能。参考页面是结构依据，题解、讨论、排行榜等入口不照搬。

## 可访问性

编辑器名称明确为“C++ 代码编辑器”；输入和输出样例有各自标签与复制反馈。编辑器 Tab 焦点退出方式
可发现且可用，不形成键盘陷阱；窄屏切换遵循标签页语义。手机使用已有 TextEditor 回退，持续保持相同
草稿和状态。双主题、缩放、长内容与辅助显示模式按 PROMPT.md 自检八问验收。

## 调试与恢复

需要反馈问题时提供当前题目/版本、页面状态与公开 requestId；不把源码、Cookie 或本机草稿写进日志。
本轮真实验收路径是登录 → 打开题目 → 编辑 → 刷新恢复 → 切题/登出/重登 → 检查按钮暂未开放。
