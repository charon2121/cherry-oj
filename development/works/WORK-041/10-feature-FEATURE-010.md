# FEATURE-010：建立题目阅读与 Monaco 编码工作台

## 为什么做

读题和写代码应当在同一页完成。现在题目右侧只有固定的登录提示，已经登录的人也看不到编辑器，容易
误以为账号失效。本次让用户能一边读题一边写 C++，刷新后恢复自己的代码，并明确哪些能力尚未开放。

## 使用者

浏览公开题目的访客，以及已登录的 USER 和 ADMIN。管理员进入用户端题目详情时同样可以编写代码。

## 入口

现有题库列表 `/problems` 点击题目后进入 `/problems/$slug`；本次改变的是题目详情页，题库列表保持原有
筛选、分页与布局。

## 正常流程

进入题目 → 左侧阅读题面与样例 → 右侧确认 C++、加载起始代码或本地草稿 → 编辑并自动保存到本机 →
刷新或再次进入同一版本恢复代码。尚未登录时左侧仍可阅读，右侧展示起始代码预览和登录入口；登录后
返回原题进入编辑状态。

## 业务规则

- REQ-001：桌面宽屏以接近均衡的左右双栏呈现，左侧题面、输入输出说明、范围和样例，右侧代码；两栏
  独立滚动，持续可达的工具栏显示当前题目、语言和草稿状态，不保留窄元信息侧栏的旧构图。
- REQ-002：桌面使用 Monaco Editor，支持 C++ 高亮、行号、缩进、撤销/重做、查找；首版不承诺 C++
  语言服务器、实时编译诊断或调试器。代码模式仍为现有 ACM，用户编写含 main 的完整程序。
- REQ-003：登录状态复用系统真实会话。已登录且无需改密的 USER/ADMIN 直接编辑；访客只读预览并登录；
  会话加载或查询失败有独立提示与重试，不能被误写成未登录；必须改密的账号给出改密入口。
- REQ-004：优先恢复“账号 × 题目版本 × 语言”对应的本地草稿，无草稿时使用题目发布的 starterCode；
  空字符串也是有效草稿，不能被起始代码覆盖。没有 starterCode 时从空编辑器开始。
- REQ-005：草稿仅保存在当前浏览器，状态明确显示“保存中”“已保存到本机”或“保存失败，请复制备份”。
  切题、换账号、题目发布新版本互不覆盖；恢复起始代码前确认，并只改变当前草稿。
- REQ-006：退出或会话失效后停止编辑和写入并隐藏原账号代码；已有草稿保留在该账号本机空间，重新登录
  同一账号才能从页面恢复。账号隔离不等于设备加密；不承诺跨设备同步。
- REQ-007：“运行”“提交”展示为不可用，并在旁边持续显示“暂未开放”；不会调用不存在的接口、模拟
  排队或生成假结果。本轮不提供可编辑自定义输入、历史提交或判题结果页。

## 边界与失败

题目 404、加载中、请求失败与重试保持独立。编辑器加载失败不能覆盖草稿；提供重试和已有代码复制。
本机存储被禁用或容量不足时仍可编辑和复制，清楚提示尚未保存；有未持久化改动时离开页面需保护。
后台同题数据刷新不能把新 starterCode 写回正在编辑的缓冲区；发现版本更新时由用户显式切换并使用新键。
多个标签页修改同一草稿时提示冲突，不静默覆盖另一标签页的新内容，保留当前缓冲区供复制或确认覆盖。

## 要求

- REQ-008：两个现有主题使用同一结构和语义设计值；窄屏采用题面/代码切换，切换不丢代码。手机触控端
  使用已有轻量编辑器回退，桌面仍用 Monaco，见 DESIGN-035 的官方支持范围依据。
- REQ-009：键盘可进入和退出编辑器、操作面板与复制样例，320px 和 200% 缩放下操作不裁切；错误与禁用
  原因有可读文字，不能只靠颜色表达。
- REQ-010：编辑器与 worker 随本站静态资源交付，仅在题目代码区需要时加载；不向外部 CDN 或分析服务
  发送源码。原登录、安全链路、后台 CodeMirror 编辑器和公开题目接口语义保持不变。

## 验收标准

- AC-001：宽屏左右同时读题与编码，各自滚动；切换深浅主题后文字与编辑器状态清楚，返回题库正常。
- AC-002：已登录 USER、ADMIN 均直接看到可编辑代码区，不出现“登录后开始答题”；访客、加载、网络
  错误、会话失效和强制改密分别显示正确入口与提示。
- AC-003：C++ 高亮、缩进、撤销重做、查找可用；无草稿时加载该版本 starterCode，清空并刷新后保持空。
- AC-004：编辑后刷新恢复；切题、切账号和发布新版本不串用草稿；恢复起始代码的取消/确认均符合预期。
- AC-005：存储不可用、编辑器加载失败、跨标签页冲突和会话过期不静默丢代码、不显示虚假的保存成功。
- AC-006：运行与提交始终标示暂未开放；点击、键盘和快捷键都不能产生 run/submission 请求或假结果。
- AC-007：320px、200% 缩放、键盘、长中文、forced-colors、reduced-motion 与手机回退可用，切换面板不丢草稿。
- AC-008：浏览题库列表和后台不加载 Monaco；代码区仅请求本站编辑器资源，worker 正常；原公开详情、
  登录回跳、后台编辑和 Web 质量检查无回归。

## 不做什么

本轮不开发后端自测、Submission/Kafka 判题、正式提交、历史回看、CORE、新语言、题解、讨论、AI 助手、
LSP、多人协作或云端草稿同步。不以本工作完成宣称 WORK-002 的完整答题闭环已交付。
