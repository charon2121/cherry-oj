# PLAN-027：建立题目阅读与 Monaco 编码工作台

## 目标

交付 FEATURE-010 的前端读题/编码切片。运行、提交、判题和历史明确保持未开放，本轮不推进 WORK-002。

## 改动区域

TASK-075 约束 Web 题目工作台、Monaco 本地适配、页面模板、草稿和测试；必要的设计系统接入与文档同步
也列在该任务边界。Java、Go、契约、数据库、Compose 不进入写范围。

## 阶段与顺序

1. 本轮：完成只读诊断、功能与体验定义、技术方案和任务，文档进入 review；WORK/TASK 保持 todo。
2. 负责人审阅并签署意图闸、允许实施后：建立 Monaco 薄适配与主题/worker，再组装双栏与窄屏工作台。
3. 接入真实会话与本机草稿，覆盖身份切换、空代码、存储失败、版本切换和离开保护。
4. 回归登录、公开详情与后台；记录构建大小及双主题浏览器证据，修复发现的问题后交付人工体验。

## 并行与依赖

本轮仅并行只读核查后端缺口。实施时编辑器适配与草稿工具可按明确子边界并行，整合必须在它们通过
定向检查后进行；验证与结果记录在最后，不以 mock 结果宣称后端能力存在。

## 迁移与交付

新增 Web 依赖并锁版本，部署静态资源即可生效；后端无需修改。保留本机草稿的版本化命名空间。交付时
向用户说明已完成的编辑能力、草稿仅在本机和执行按钮尚未开放，避免把页面完成当成答题闭环完成。

## 风险

Monaco 体积与 worker、双主题适配、手机支持、跨账号或跨标签页覆盖是主要风险。任何需要新增 API、
迁移、语言服务器或运行用户代码的方案都超出当前范围，先回到定义层。

## 验证

先运行草稿/会话/编辑器定向测试，再运行 npm run check、npm run build、npm run storybook:build 和
受影响 Playwright 用例。真实浏览器完成 FEATURE-010 AC-001～AC-008，截图回答 PROMPT.md 自检八问。
保留已登录与未登录、存储失败、双主题、320px/200% 缩放的证据；格式通过不能代替视觉和交互验收。

## 回退

回退本工作 Web 提交并重新发布上一版静态资源；本机草稿键保留，旧页面忽略新数据，避免回退造成代码
删除。不回退数据库、后端、判题节点或其他已完成工作。
