# EXPERIENCE-016：统一页面任务优先布局并移除状态占位

## 体验类型

用户体验与开发体验。用户侧把首屏从“先解释页面”改为“直接开始任务”；开发侧建立可复用的壳层间距和
滚动合同，避免新页面再次自行选择 `py-10`、`py-16` 或 `py-20`。

## 入口与主流程

### 用户端

- 固定页头之后留 24px，直接出现页面核心内容：题库筛选、题目业务标题/题面、密码表单或真实状态。
  首页不再展示 REST 状态，也不新增占位内容。
- ADMIN 继续从头像菜单进入“管理中心”；访客和 USER 的账号入口行为不变。

### 管理端

- 页头之后同样留 24px。用户账号直接从创建账号操作与列表开始；题目管理直接从新建/筛选/列表开始；
  工作台保留题目版本这个业务对象标题和状态，而不是额外增加页面介绍。
- “返回用户端”进入头像菜单，与“修改密码”“退出登录”形成账号/空间操作组；页头只保留移动菜单、
  品牌、主题和账号入口。
- 桌面 Sidebar 固定在 Header 下方，中央 main 独立滚动。移动端仍通过 Sheet 导航。

## 异常状态

加载、空、错误、无权限和 not-found 继续使用现有 `AsyncState` 或错误页面标题；这些标题解释当前状态，
不是被禁止的页面介绍。登录态加载/失败时账号菜单仍显示现有反馈。内容不足一屏时 main 不应出现虚假
滚动；内容很长时聚焦控件和锚点要滚入中央容器的可见区域。

## 交互与文案

- 不再出现“公开题库 / 选择下一道题 / 题面来自……”或“管理中心 / 用户账号 / 创建、停用……”这种
  连续页面介绍。相关语义由当前导航、控件标签和业务内容表达。
- “返回用户端”必须写全，不能只用返回箭头；菜单项使用方向明确的图标和原生链接语义。
- 删除“正在连接 Gateway”“REST API 暂时不可用”“REST API 已连通”等产品文案。
- 题目名称、版本号、表单标题、错误标题和空状态标题保持具体，不改成模糊无标题容器。

## 可访问性

- 每个路由仍有有意义的 document title，并在需要时保留视觉隐藏的 H1；不得以“视觉上不显示标题”为由
  删除语义导航。
- Skip link 继续落到 main；管理 main 成为滚动容器后，焦点跳转和键盘滚动必须操作内容区，不被固定
  Header 遮挡。
- 账号菜单的“返回用户端”支持键盘打开、聚焦、激活和关闭后焦点恢复；320px 不因移除独立按钮而损失
  返回能力。
- 两个主题、forced-colors、200% 缩放与 reduced-motion 不改变布局语义；不新增只靠颜色或动画的提示。

## 调试与恢复

Playwright 用实际 bounding box 断言 Header 底边至首个主体为 24px，并在长管理页验证
`main.scrollTop` 变化而 document/Sidebar 位置不变。若嵌套滚动破坏路由恢复或焦点，可整体回退 Admin
Shell 的视口滚动改动；API 删除与布局调整可独立回退。服务可用性继续通过 Actuator 和日志定位，不在
首页恢复探针。
