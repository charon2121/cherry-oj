# WORK-015：建立 Cherry OJ Web 设计系统

类型：基建 · 历史工作

## 为什么做

Web 缺少一致的视觉与组件规则，页面容易各自设计。

## 打算怎么解决

建立主题、设计合同、组件和验证方法。

## 范围和代价

设计值由 Web 代码维护；视觉是否符合预期需要人判断。

## 怎样算完成

主题与组件能按同一合同使用，关键布局和可访问性可验证。

原记录标为已实施；技术完成与人工接受需分别查原始记录。
