# empty-case：空输入与空输出

读若干整数，输出它们的和；**没有整数时什么都不输出**。这道题同时检验测试数据协议允许零字节文件。

| 测试点 | 输入 → 期望输出 |
|---|---|
| `1` | 空文件 → 空文件 |
| `2` | 只有一个换行 → 空文件 |

| 提交 | 整体 | 逐点 | 为什么存在 |
|---|---|---|---|
| `ac_silent` | AC | AC AC | 什么都不输出，空对空 |
| `ac_reads_eof` | AC | AC AC | 读到 EOF，没有整数就不输出 |
| `wa_prints_text` | WA | WA WA | 期望是空，多输出就是错 |
