# sum-large：64 位整数

读 `n` 和 `n` 个 `long long`，输出总和（总和不超过 `long long`）。

| 测试点 | 输入特点 |
|---|---|
| `1` | 小数：`1 2 3` |
| `2` | 总和超过 `2^31`：三个 `2000000000` |
| `3` | 总和接近 `2^63`：两个 `2^62 - 1` |
| `4` | 含负数，总和 `-82` 在 `int` 范围内 |

| 提交 | 整体 | 逐点 | 为什么存在 |
|---|---|---|---|
| `ac_int64` | AC | AC×4 | 基线 |
| `ac_int128` | AC | AC×4 | 更宽的类型同样通过 |
| `wa_int32` | WA | AC WA WA AC | 用 `int` 累加，只有总和越界的点才错 |

参考解 A 顺序累加，B 分治求和。
