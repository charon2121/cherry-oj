# big-output：输出上限（需要 `backend:linux`）

读 `n`，输出 `1` 到 `n`，每个数一行。输出上限由执行器的 stdout 硬界（1 MiB）决定，只有有真实隔离的后端上才可比。

| 测试点 | 输入 |
|---|---|
| `1` | `n = 100`（约 0.3 KB） |
| `2` | `n = 50000`（约 0.3 MB，低于上限） |

| 提交 | 整体 | 逐点 | 为什么存在 |
|---|---|---|---|
| `ac_modest` | AC | AC AC | 输出远小于上限 |
| `ole_flood` | OLE | OLE OLE | 忽略输入，无限输出 |
| `probe_near_limit` | 探测项 | 只记录 | 输出约 1 MiB 减一点，观察边界；预期值只是占位，不进断言 |
