# sort-numbers：中等规模输入输出与时间

读 `n` 和 `n` 个整数，按升序输出，空格分隔。

| 测试点 | 输入 |
|---|---|
| `1` | `n = 1` |
| `2` | `n = 10`，含重复 |
| `3` | `n = 1000`，互不相同、完全逆序 |
| `4` | `n = 10^5`，随机，取值范围 0–9999 所以大量重复 |
| `5` | `n = 10^5`，全部相等 |

| 提交 | 整体 | 逐点 | 为什么存在 |
|---|---|---|---|
| `ac_std_sort` | AC | AC×5 | 基线 |
| `ac_qsort` | AC | AC×5 | C 的 `qsort` 同样通过 |
| `tle_bubble` | TLE | AC AC AC TLE TLE | `n = 1000` 够快，`n = 10^5` 的冒泡远超 CPU 限制 |
| `wa_unique` | WA | AC WA AC WA WA | 排序后去重，只有含重复的点才错 |

参考解 A 用内置排序，B 是手写堆排序。
