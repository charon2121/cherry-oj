# assets

Intentionally empty. The mounted source package (`linear-app/`) contained no
logo files, font binaries, icons, illustrations or imagery — it is a
token/CSS-only package. Nothing was drawn or generated to fill the gap.

Drop real files here when available:
- `logo.svg` / `wordmark.svg` — the brand mark (thumbnail and NavBar pick it up)
- `fonts/InterVariable.woff2`, `fonts/BerkeleyMono-*.woff2` — replaces the
  Google Fonts substitutes declared in `tokens/fonts.css`
- `icons/` — the real icon set, replacing the inlined Lucide paths in the UI kits
