# 参照实测记录

## 这份文件为什么存在

设计系统的骨架尺寸、字重、线宽、浮层材质与暗色主题的明度台阶来自对 **linear.app 真实页面**的实测。
此前两份参照——Claude Design 下载包与 Figma 社区文件——都是二手还原，照着还原品校准让这个仓库
返工了四轮；旧的 Figma 实测保留在 [`measurements-figma-community.md`](./measurements-figma-community.md)
只作历史。

**这里只记录事实（量到了什么），不记录规则（该怎么做）。** 规则在
[`../design-system.md`](../design-system.md) §7.2 与 §7.3，它们引用这里的数字。

## 字体与字重

Inter Variable。用到的字重：

| 字重 | 用在哪里 |
|---|---|
| 450 | 正文、标识、计数、日期 |
| 500 | 导航项、胶囊、行标题、分组标签、属性值、区块小标题 |
| 600 | 详情大标题（24px）、区块标题（15px） |

字号：12px（胶囊、日期、侧栏分组名）、13px（界面主力）、15px（详情正文、区块标题）、24px（详情标题）。
标识有 `-0.26px` 字距，其余为 0；详情标题与正文 `-0.1px`。

## 颜色（暗色）

全部以 LCH 给出，色相 272、彩度约 0.4–1.5，**几乎是中性灰**，不是蓝紫灰。明度台阶：

| 角色 | L |
|---|---|
| 画布、侧栏 | 2.6 |
| 主内容面板 | 5.5 |
| 分组带、未选胶囊 | 9.2–10.1 |
| 浮层底 | 12.7 |
| 面板边 | 13.1 |
| 选中胶囊、选中导航 | 16.7 |
| 浮层边 | 25.7 |
| 灰字 | 60.6–61.8 |
| 次亮字 | 90.5 |
| 最亮字 | 100 |

本仓库 `cherry-black` 把这些值换算成 sRGB 后写入主题文件；品牌色仍是 Cherry 红，不采用参照的紫色。

## 按钮

全部是胶囊（`border-radius: 9999px`），0.5px 透明边。

| 种类 | 实测（暗色） | 浅色差异 |
|---|---|---|
| 主按钮 | 高 28，左右 10，12px/500，品牌实心底，阴影 `0 0.5px 1px 1px`（30% 黑） | 阴影换成 `0 3px 6px -2px` 2% 与 `0 1px 1px` 4% |
| 次要按钮 | 高 28，左右 10，12px/500，比面板亮一档的底，次亮字，无阴影 | 白底，加 0.5px 9% 黑环与同上两层阴影 |
| 幽灵按钮 | 高 32，左右 12，13px/500，透明底，次亮字 | 同 |
| 图标按钮 | 28×28 胶囊，左右 2 | 同 |
| 属性胶囊（对话框内） | 高 24，左 6 右 8，12px，比面板亮约三档的底，灰字 | 白底加 0.5px 环 |

| 控件 | 实测 |
|---|---|

| 开关 | 30×20 胶囊；开为品牌色；关为中灰 |

## 设置页成组卡片

圆角 10，底与分组带同档；暗色用 0.5px 8% 白环加主面板阴影，浅色用 0.5px 9% 黑环加两层极轻阴影。
每行高 65、内边距 16；行间是左右各内缩 16px 的 0.5px 分隔线。行标签 13px/500 最亮，说明 12px/450 灰。
页标题 24px/500，区段标题 15px/500。

## 浅色主题

Light 与 Pure Light 都是中性灰（彩度 0–1.25）。本仓库 `pure-white` 对应 **Pure Light**。

| 角色 | Light（L） | Pure Light（L） |
|---|---|---|
| 画布、侧栏 | 94.4 | 100 |
| 主内容面板 | 97.9，0.5px 边 89.8 | 100，0.5px 边 94.6 |
| 分组带 | 94.4 | 97.7 |
| 未选胶囊 | 100 + 0.5px 环 | 100 + 0.5px 环 |
| 选中胶囊 | 93.5 | 97.0 |
| 选中导航 | 89.5 | — |
| 最亮字 | 9.8 | 10.4 |
| 次亮字 | 19.6 | — |
| 灰字 | 37.8–39.2 | 41.4 |
| 对话框边 | 91.9 | 94.6 |

主内容面板阴影：`0 3px 6px -2px` 2% 与 `0 1px 1px` 4%。

## 实测推翻了什么

| 旧规则（来自 Figma 社区还原） | 实测事实 |
|---|---|
| 侧栏 220px，顶栏 56px 横跨全宽 | 侧栏 244px；主内容是内嵌面板，44px 顶栏在面板内 |
| 字重只有 400 和 500 | 450 / 500 / 600 三档 |
| 列表行间 1px hairline | 行间没有分隔线；线宽是 0.5px |
| 浮层用模糊 + 大柔阴影 | 没有模糊；浮层三层小阴影，对话框五层淡阴影 |
| 焦点是控件边框变色 | 边框不变，加一条贴边 1px outline |
| 按钮圆角 4px，控件圆角 4–6px | 按钮全是胶囊；输入框与下拉圆角 8px |
